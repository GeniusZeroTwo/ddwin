# Linux 一键重装/DD至 Windows 官方中文版脚本 (`dd-win.sh`)

一个高度自动化、健壮且专为云服务器/VPS 定制的 **Linux 快速重装/DD 到 Windows 官方中文版** 脚本。

脚本支持直接拉取 **微软官方原生纯净中文版系统**（无任何第三方后门、木马或精简风险），全流程无人值守自动安装，并针对各类云主机环境（KVM、Xen、Proxmox、VMware、独立服务器）进行了全方位防失联优化。

---

## 🌟 核心特性与深度优化

| 优化维度 | 传统 DD 脚本常见痛点 | 本脚本专项优化方案 |
| :--- | :--- | :--- |
| **镜像来源** | 第三方打包的精简镜像，容易夹带后门或精简过度缺少系统组件 | **100% 微软官方 MSDN/评估中心中文原版**，纯净安全 |
| **账户与密码** | 固定弱密码或需手动进系统重置，易遭扫描破解或因复杂度不足装机卡死 | **支持自定义账户名与密码**，内置 Windows Server 复杂度强校验，支持一键生成高熵密码 |
| **网卡与存储驱动** | 云服务器因缺少 VirtIO 驱动导致开机蓝屏 (`INACCESSIBLE_BOOT_DEVICE`) 或无网卡 | **全量自动注入 RedHat 官方 VirtIO 驱动全集** (VioStor、VioSCSI、NetKVM、Balloon、Serial) |
| **静态 IP 保留** | 部分机房 (Hetzner、OVH、阿里云ECS等) 为静态绑定 IP，安装后无法获取 DHCP 导致永久断网 | **自动提取并持久化当前 Linux 网络参数** (IP、网关、掩码、DNS)，初次启动自动探测并自愈配置 |
| **远程桌面 (RDP)** | 默认未开启或被系统防火墙拦截，无法连接 3389 | **自动激活 RDP 服务**，关闭 NLA 协议限制，防火墙放行自定义端口，自动放行 ICMP (Ping) |
| **全盘自动扩容** | 安装后 C 盘仅保留镜像原始大小 (如 15G)，剩余空间变成未分配空间 | **注入 First-Logon 自动化扩容任务**，启动即自动拉伸 C 盘占满全部硬盘容量 |
| **低内存防护** | 512MB ~ 1GB 内存小鸡解包 ISO 时极易 OOM 崩溃 | **智能检测 RAM 大小**，内存不足 2GB 时自动创建 2GB 临时 Swap 虚拟内存保障顺利安装 |
| **引导方式自适应** | 手动区分 MBR 与 GPT 容易选错导致无法开机 | **自动检测 UEFI 与 Legacy BIOS**，自动构建匹配的 EFI 分区或引导扇区 |
| **国内节点加速** | 国内机房拉取海外 GitHub 仓库或镜像源经常超时或断连 | **智能地理位置探测**，境内 VPS 自动走国内加速反代通道与 CDN 源 |


### 2. 静默一键命令 (适合脚本自动化与批量部署)

你也可以通过命令行参数一步到位直接执行，无需人工守候：

#### 示例 A: 一键安装 Windows Server 2022 (推荐)
```bash
bash dd-win.sh -v 2022 -p "P@ssw0rd2022!" -y
```

#### 示例 B: 一键安装 Windows Server 2025 并修改 RDP 端口为 33890
```bash
bash dd-win.sh -v 2025 -u "Administrator" -p "Win2025_Admin#" --port 33890 -y
```

#### 示例 C: 一键安装轻量级 Windows 10 LTSC 2021
```bash
bash dd-win.sh -v 10 -p "MyLTSC#2026Secure" -y
```

#### 示例 D: 使用自定义 ISO 镜像安装
```bash
bash dd-win.sh --iso "https://example.com/custom_windows.iso" -p "CustomPass@123" -y
```

## 📋 命令行参数汇总

| 参数 | 长参数 | 说明 | 默认值 |

| `-p` | `--password` | 管理员登录密码（需符合复杂度策略） | 留空则交互输入或自动生成 |

## 🔑 Windows 密码复杂度规范说明

为防止安装完成后因密码不合规导致 Windows 安装程序卡在“密码不满足策略”界面无法进入桌面，脚本内置了严格的合规性校验。

密码需同时满足以下条件：
1. **长度**：至少 8 位（推荐 10 位以上）。
2. **字符集组合**：必须包含以下 4 类中的至少 **3 类**：
   - 英文大写字母 (`A-Z`)
   - 英文小写字母 (`a-z`)
   - 数字 (`0-9`)
   - 特殊字符符号 (`!@#$%^&*()_+-=[]{}` 等)
3. **不能包含用户名**：密码中不能含有用户名本身的字符（不区分大小写）。

> **贴心功能**：如果交互模式下直接按回车，脚本会自动为你生成一个符合微软策略的随机高强度密码，并在最终确认卡片中清晰展示！

## 🖥️ 安装完成后如何连接

1. **等待系统部署完成**：
   - 脚本执行后服务器将自动重启进入无人值守配置阶段。
   - 一般耗时约 **10 ~ 20 分钟**（视主机网络下载带宽与硬盘写入性能而定）。
2. **连接远程桌面 (RDP)**：
   - **Windows 电脑**：按 `Win + R` 输入 `mstsc`，在计算机一栏输入 `你的服务器IP:远程端口`（默认端口 3389 时可直接输入 IP），输入用户名与密码即可登录。
   - **macOS 电脑**：在 Mac App Store 下载 `Microsoft Remote Desktop`，新建 PC 并填入 IP 与凭据即可。
   - **手机/平板**：使用 `RD Client` 客户端连接。

## 🛠️ 常见问题与避坑指南 (FAQ)

### Q1: 如果连接不上远程桌面，怎么查看安装进度？
- 云服务商（如腾讯云、阿里云、甲骨文、Hetzner、Vultr 等）后台控制面板通常提供 **VNC / 控制台 (Console)** 功能。
- 如果超过 20 分钟仍无法连接 RDP，可打开 VNC 界面，即可直观查看 Windows 是否正在加载驱动、释放系统镜像或正在初次启动。

### Q2: 为什么我的服务器只有 1GB 内存也能顺利安装？
- 脚本内置了 **内存自适应机制**。当探测到当前主机可用内存低于 2GB 时，会自动在磁盘建立 2GB 临时 Swap 虚拟内存，确保解压和驱动打入过程不发生 Out of Memory 导致系统崩溃。

### Q3: 为什么重装后硬盘容量变小了？
- 无需担心！脚本在 `unattend.xml` 的第一登录序列中注入了 `diskpart extend` 扩容指令。首次进系统后会自动将 C 盘拉伸扩容至该磁盘的物理上限。如果个别机型未生效，可在 Windows 中打开 `计算机管理 -> 磁盘管理`，右键 C 盘点击“扩展卷”即可。
